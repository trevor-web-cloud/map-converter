📍 Google Maps Plus Code 使用說明（點開看教學）

什麼是 Plus Code？

Plus Code 是 Google 的地點編碼，用一串字元代表經緯度。完整碼像 8Q7C5RJG+F63（+ 前面 8 字），短碼像 5RJG+F6（+ 前面只有 4 字，需搭配城市名）。

怎麼從 Google Maps App 複製 Plus Code？

  1. 在 Google Maps App 點地點名稱，打開地點卡片（不要長按地圖空地，那會拿到別的位置的碼）。
  2. 往下滑到「關於」區，找到 Plus Code 那一行（例如 5RJG+F6 金海市 南韓慶尚南道）。
  3. 點那行複製，或手動記下短碼 + 城市名。

怎麼貼到轉換頁？

  • 完整碼：直接貼 8Q7C5RJG+F63 就好，不用加城市名。
  • 短碼：一定要加上城市名，例如貼 5RJG+F6 金海市。只貼短碼 5RJG+F6 會提示需要參考位置，不會產生座標。
  • 貼上後網頁會自動開始轉換；如果沒有自動開始，請按「已經貼好了，開始轉換」。成功後往下點一個地圖按鈕即可。

注意事項

  • App 顯示的都是短碼，務必連城市名一起貼。
  • 短碼的格子字不同就是不同位置：F6 是飯店、FVG 是旁邊公園，相差約 150 公尺。請確認是從地點卡片複製的碼，不是長按空地拿到的碼。
  • Plus Code 代表一塊範圍，不是精確圖釘；轉換頁放的是範圍中心。+ 後面 2 字、還原後共 10 字的碼，範圍約 14 公尺見方，中心和店家最多可能差約 10 公尺；+ 後面 3 字、還原後共 11 字的碼，範圍約 3 公尺見方，落差才約 2 公尺。要精準找店，請改貼店家的分享連結，或到現場再以店名、招牌確認。
